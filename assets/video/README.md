# Видео

| Файл | Что это |
|---|---|
| `source/copilot-main-video.mp4` | исходник как прислали: 1440×900, 29.97 к/с, 24.22 с |
| `main.mp4` | то, что играет в прототипе: без звука, ключевой кадр на каждом кадре |

Исходник совпадает с кадром макета один в один, кроп ничего не срезает. Если
следующая версия придёт шире, скрипт обрежет её по центру.

## Зачем перекодирование

В обычном видео ключевой кадр стоит раз в 2–5 секунд. Когда мы перематываем
ролик скроллом, браузер на каждый кадр должен доехать от ближайшего ключевого —
получается рывками и с задержкой.

`scripts/encode-video.sh` кодирует с `-g 1`: ключевой кадр на каждом кадре,
любая секунда показывается мгновенно. Заодно приводит кадр к 1440×900.

```bash
./scripts/encode-video.sh assets/video/source/copilot-main-video.mp4
```

Текущий файл собран с `CRF=22` и весит 22 МБ. Это подобрано под лимит
Cloudflare Pages: 25 МиБ на файл. Против `CRF=18` (31 МБ) разницы на глаз нет,
сравнивали на ровных плашках, где полосы вылезли бы первыми.

## Если ролик поменяется

1. Положить новый исходник в `source/`.
2. Прогнать скрипт.
3. Пересчитать интервалы остановок в `js/timeline.js` — они привязаны
   к конкретным кадрам.

## Ограничения по весу

- До 100 МБ на файл — обычный git.
- Больше — понадобится Git LFS.
