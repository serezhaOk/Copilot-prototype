# Видео

## Куда класть

| Что | Путь |
|---|---|
| **Исходник как есть** (mov / mp4 / что угодно) | `assets/video/source/` |
| Готовое видео для десктопа | `assets/video/main.mp4` |
| Готовое видео для мобилок | `assets/video/main-mobile.mp4` |

Достаточно закинуть исходник в `source/` — остальное соберётся скриптом.

## Почему нельзя просто положить исходник и назвать его main.mp4

В обычном видео ключевой кадр стоит раз в 2–5 секунд. Когда мы перематываем
видео скроллом, браузер на каждый кадр должен доехать от ближайшего ключевого —
получается рывками и с задержкой.

`scripts/encode-video.sh` перекодирует ролик с ключевым кадром на **каждом**
кадре (`-g 1`). Файл станет тяжелее в 2–4 раза, зато перемотка будет мгновенной.

```bash
./scripts/encode-video.sh assets/video/source/имя-файла.mp4
```

## Ограничения по весу

- До 100 МБ на файл — обычный git, всё нормально.
- Больше 100 МБ — GitHub не примет, нужен Git LFS.
- Для 17 секунд 1080p при CRF 23 ожидаем примерно 20–50 МБ. Если вышло сильно
  больше — перезапустить с `CRF=27`.
