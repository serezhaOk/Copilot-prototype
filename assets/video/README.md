# Видео

| Файл | Что это |
|---|---|
| `source/copilot-main-video.mp4` | исходник как прислали: 4096×1962, 23.976 к/с, 25.53 с |
| `main.mp4` | то, что играет в прототипе: 1440×900, без звука, ключевой кадр на каждом кадре |

Исходник шире кадра макета: 2.09:1 против 1.6:1. Скрипт масштабирует по высоте
и обрезает по центру, срезая около 23% ширины. Композиции ассетов это не ломает,
но важные детали у самых краёв кадра потеряются.

## Зачем перекодирование

В обычном видео ключевой кадр стоит раз в 2–5 секунд. Когда мы перематываем
ролик скроллом, браузер на каждый кадр должен доехать от ближайшего ключевого —
получается рывками и с задержкой.

`scripts/encode-video.sh` кодирует с `-g 1`: ключевой кадр на каждом кадре,
любая секунда показывается мгновенно. Заодно обрезает кадр до 1440×900 —
иначе браузер декодировал бы 4096 пикселей ширины на каждую перемотку.

```bash
./scripts/encode-video.sh assets/video/source/copilot-main-video.mp4
```

Текущий файл собран с `CRF=18` и весит 31 МБ. На больших плашках ровного
цвета низкий CRF заметно убирает полосы, поэтому экономить тут не стоит.

## Если ролик поменяется

1. Положить новый исходник в `source/`.
2. Прогнать скрипт.
3. Пересчитать интервалы остановок в `js/timeline.js` — они привязаны
   к конкретным кадрам.

## Ограничения по весу

- До 100 МБ на файл — обычный git.
- Больше — понадобится Git LFS.
