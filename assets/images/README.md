# Ассеты

Сюда кладём картинки, которые появляются на остановках видео.

## Именование

По порядку появления, с ведущим нулём:

```
01-название.png
02-название.png
03-название.png
```

Порядок в имени файла — только для удобства. Реальный порядок появления
задаётся полем `at` в `js/timeline.js`.

## Требования

- **Формат:** PNG с прозрачностью, если ассет ложится поверх видео;
  JPG — если это плотная плашка без прозрачных краёв. WebP тоже подойдёт.
- **Ширина:** 2× от того, как ассет должен выглядеть на экране
  (для retina). Блок по умолчанию 720 px, значит картинка ≈ 1440 px.
- **Текст:** если текст вшит в картинку — он не будет масштабироваться
  и не прочитается на мобилке. Лучше присылать картинку без текста,
  а текст — отдельно, я его сверстаю.
