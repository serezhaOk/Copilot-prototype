# Ассеты

Полноэкранные PNG с прозрачностью, ровно под кадр макета 1440×900,
экспортированы в 2× (2880×1800). Ложатся на видео пиксель в пиксель.

## Именование

```
порядок. имя. НАЧАЛО – КОНЕЦ.png
01. framework. 00_00 – 03_00.png
```

Файл без интервала в имени — статичный слой, не привязанный к таймлайну.
Сейчас такой один: `00. static header.png`, шапка сайта. Она подключается
не через `stops`, а через `header` в `js/timeline.js`, и видна всегда.

Интервал в имени — секунды и кадры при 30 fps: `07_20` = 7 с 20 кадров =
7.667 с. Это интервал видео, на котором ассет находится на экране.

Имя файла — только для людей. Что реально попадает в прототип, задаётся
в `js/timeline.js`: там прописаны и путь, и `from` / `to`.

## Требования

- Размер 2880×1800 (2× от кадра 1440×900), PNG с альфой.
  `00. static header.png` пришёл 2878×1800 — на два пикселя уже. Он тянется
  до ширины кадра, на глаз незаметно, но при следующем экспорте лучше
  выровнять.
- Композиция рассчитана на конкретный кадр видео: например, у `03. book`
  текстовая карточка стоит справа, потому что в кадре 7.67–9.00 книга лежит
  слева на приборной панели. При замене ролика интервалы придётся пересчитать.
- Текст вшит в картинку. Он не масштабируется и не выделяется — для прототипа
  это нормально, для вёрстки в продакшн текст надо будет вынести в HTML.

## Как добавить новый ассет

1. Положить файл сюда.
2. Дописать остановку в `js/timeline.js`.
3. Интервал можно снять прямо в прототипе: `D` включает панель, `T` пишет
   текущий таймкод в формате `СС_КК`.
