# Горизонтальная галерея в разделе «Одежда»

Вертикальный скролл работает ровно как раньше. Когда доскроллили до раздела
и заголовок «ОДЕЖДА» полностью проявился — вещи можно листать вбок. Та, что
встала по центру, считается активной, и под ней появляется её плашка
с описанием. У всех остальных плашка полностью прозрачная.

## Чем листать

| Способ | Как |
|---|---|
| Тачпад | горизонтальный свайп двумя пальцами |
| Мышь | зажать и потащить вбок |
| Клавиатура | стрелки влево-вправо |
| Клик | нажать на вещь, которая стоит сбоку |

Стрелки вверх-вниз, вертикальное колесо и вертикальное перетаскивание
галерея не трогает — они уходят странице, как и раньше.

Логика простая: жест считается «нашим», только если по горизонтали ушли
дальше, чем по вертикали. Иначе браузер получает событие нетронутым.

## Когда галерея активна

Только пока ассет раздела виден целиком — то есть внутри «стоянки»,
между проявлением и угасанием. На въезде и выезде галерея выключена,
чтобы нельзя было случайно перелистнуть вещь, проскакивая раздел мимо.

## Настройка

Всё в `js/timeline.js`, в остановке `clothes`, ключ `gallery`. Координаты —
в системе кадра макета 1440×900, поэтому галерея масштабируется вместе с ним.

| Поле | Что делает |
|---|---|
| `itemWidth` | ширина холста вещи; высота считается сама по пропорциям файла |
| `itemTop` | отступ холста вещи от верха кадра |
| `step` | расстояние между соседними вещами; меньше — соседи сильнее заглядывают в кадр |
| `plateWidth` | ширина плашки с описанием |
| `plateTop` | положение плашки по вертикали в кадре |
| `hint` | текст подсказки; `null` — убрать совсем |
| `items` | список вещей: `name`, `image`, `plate` |

Подсказка «ЛИСТАЙТЕ» висит в правом верхнем углу и гаснет насовсем после
первого перелистывания. В референсе её нет — если для показа клиенту она
лишняя, поставить `hint: null`.

## Про ассеты вещей

Все четыре вещи отрисованы на одном холсте 1342×1672 и позиционированы
внутри него. Поэтому в прототипе они выводятся одним размером: относительный
масштаб между курткой и кепкой уже заложен художником внутри файла, руками
его подгонять не нужно.

Плашки — 784×464, каждая в паре со своей вещью:

| Вещь | Файл | Плашка |
|---|---|---|
| Куртка | `Clothes-1.png` | `Clothes-2-1.png` |
| Футболка | `Clothes-2.png` | `Clothes-2-2.png` |
| Кепка | `Clothes-3.png` | `Clothes-3-2.png` |
| Шарф | `Clothes-4.png` | `Clothes-4-2.png` |

Нумерация плашек сбита у первой пары: у куртки плашка называется
`Clothes-2-1`, а не `Clothes-1-2`. Связка задана явно в конфиге, так что
на работу это не влияет, но при следующем экспорте имя лучше поправить.
