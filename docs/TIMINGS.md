# Тайминги

Заполни таблицу — я перенесу её в `js/timeline.js`.

| # | Секунда видео | Пауза (экранов) | Файл ассета | Положение | Текст |
|---|---|---|---|---|---|
| 1 |  |  |  |  |  |
| 2 |  |  |  |  |  |
| 3 |  |  |  |  |  |
| 4 |  |  |  |  |  |
| 5 |  |  |  |  |  |

**Секунда видео** — момент, на котором картинка замирает. Можно на глаз
(«примерно 4-я секунда»), потом подкрутим.

**Пауза** — сколько скролла человек проматывает, пока видео стоит и на экране
висит контент. `1` = один полный экран, `1.5` = полтора. По умолчанию `1.2`.

**Положение** — `center`, `left`, `right` или `bottom`.

## Как снять тайминги прямо в прототипе

1. Открыть `index.html`.
2. Нажать `D` — включится отладочная панель с текущей секундой видео.
3. Доскроллить до нужного кадра, нажать `T` — секунда запишется.
4. Внизу панели появится готовая строка для `js/timeline.js` — скопировать.
