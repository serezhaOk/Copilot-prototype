# Выкладка прототипа

Прототип — статика: HTML, CSS, JS, картинки и одно видео. Сборка не нужна,
только копирование нужных файлов в `dist/`.

```bash
node scripts/build-dist.js
```

Скрипт делает три вещи:

1. Кладёт в `dist/` только то, что нужно браузеру. Исходник видео (10 МБ)
   и документация наружу не уезжают.
2. Переименовывает ассеты в ASCII-безопасные имена и правит пути в конфиге.
   В репозитории имена с пробелами и длинным тире — людям удобно, хостингам
   не всегда. Внутри прототипа ничего не меняется.
3. Проверяет, что ни один файл не тяжелее 25 МиБ, и падает с ошибкой, если
   тяжелее. Это лимит Cloudflare Pages на файл.

Посмотреть собранное перед выкладкой:

```bash
node scripts/serve.js 8000 dist
```

Сейчас сборка весит около 25 МБ, из них 22 МБ — видео.

## Cloudflare Pages

### Вариант 1: подключить репозиторий (само пересобирается на каждый пуш)

1. Cloudflare → **Workers & Pages** → **Create** → вкладка **Pages** →
   **Connect to Git**.
2. Выбрать `serezhaOk/Copilot-prototype`, ветку
   `claude/video-scroll-sync-prototype-ca7tf6`.
3. Настройки сборки:
   - Framework preset: **None**
   - Build command: `node scripts/build-dist.js`
   - Build output directory: `dist`
4. **Save and Deploy**.

Адрес будет вида `copilot-prototype.pages.dev`. Каждый пуш в ветку
пересобирает сайт сам.

### Вариант 2: выложить с ноутбука, без подключения репозитория

```bash
node scripts/build-dist.js
npx wrangler@latest pages deploy dist --project-name=copilot-prototype
```

Первый запуск откроет браузер и попросит войти в Cloudflare. Дальше каждая
выкладка — одна команда.

### Свой домен

Pages → проект → **Custom domains** → **Set up a domain**. Если домен уже
в Cloudflare, DNS пропишется сам; если нет — Cloudflare покажет, какие
записи добавить у регистратора.

### Закрыть паролем на время показа

Cloudflare Zero Trust → **Access** → **Applications** → добавить приложение
на домен проекта. Можно пустить по списку почт клиента или по одноразовому
коду на почту. На бесплатном тарифе до 50 пользователей.

## Что важно для любого хостинга

- **Range-запросы обязательны.** Без них видео не перематывается: оно
  загрузится, но встанет на нулевой секунде, и будет выглядеть как сломанный
  скролл. Cloudflare Pages, GitHub Pages, Netlify, Vercel — умеют.
- **Лимит на размер файла.** У Cloudflare Pages 25 МиБ. Видео сейчас 22 МБ.
  Если ролик станет длиннее и вылезет за лимит — перекодировать полегче:
  `CRF=25 ./scripts/encode-video.sh assets/video/source/copilot-main-video.mp4`.
  На CRF 22 против 18 разницы на глаз нет, проверяли на ровных плашках.
- **Прототип рассчитан на десктоп.** Кадр 1440×900 масштабируется под окно,
  но на телефоне сожмётся в узкую полосу посреди экрана. Клиенту лучше
  открывать на ноутбуке.
