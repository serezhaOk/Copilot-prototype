# Scroll-driven video prototype

Видео на весь экран, привязанное к скроллу. Пользователь крутит колесо — видео
перематывается кадр за кадром. В заданных точках видео замирает и поверх него
появляется блок контента; крутим дальше — блок уходит, видео едет к следующей
точке.

Чистый HTML/CSS/JS, без сборки и зависимостей.

---

## Быстрый старт

```bash
node scripts/serve.js
# открыть http://localhost:8000
```

**Важно: открывать через этот сервер, а не двойным кликом и не через
`python3 -m http.server`.** Чтобы перематывать видео, браузеру нужны
HTTP Range-запросы. Питоновский сервер их не умеет — видео загрузится, но
намертво застрянет на нулевой секунде, и будет казаться, что сломан скролл.
`scripts/serve.js` их поддерживает и не тянет зависимостей.

Пока видео не залито, страница показывает заглушку, но скролл и появление
контента уже работают — тайминги можно проверять без файла.

---

## Куда что класть

```
assets/video/source/     ← сюда исходное видео как есть
assets/video/main.mp4    ← перекодированный вариант (делает скрипт)
assets/images/           ← ассеты, которые появляются на остановках
js/timeline.js           ← ЕДИНСТВЕННЫЙ файл настройки: тайминги и контент
docs/TIMINGS.md          ← табличка для таймингов, заполнить и прислать
```

## Подготовка видео

```bash
./scripts/encode-video.sh assets/video/source/имя-файла.mp4
```

Скрипт делает `main.mp4` (1080p) и `main-mobile.mp4` (720p) с ключевым кадром
на каждом кадре — без этого перемотка скроллом дёргается. Подробности —
в `assets/video/README.md`.

## Настройка

Всё в `js/timeline.js`:

```js
stops: [
  { at: 3.4, hold: 1.2, image: 'assets/images/01-hero.png', align: 'center' },
  { at: 8.1, hold: 1.5, image: 'assets/images/02-features.png', align: 'left' }
]
```

| Поле | Что делает |
|---|---|
| `at` | секунда видео, на которой картинка замирает |
| `hold` | длина паузы в экранах скролла (1 = один экран) |
| `image` | путь к ассету, можно `null` |
| `align` | `center` / `left` / `right` / `bottom` |
| `title`, `text` | текст, если он не вшит в картинку |
| `width` | ширина блока в px, по умолчанию 720 |

Общие настройки — там же, в блоке `scroll`:

| Поле | Что делает |
|---|---|
| `screensPerSecond` | сколько экранов скролла тратится на секунду видео |
| `smoothing` | инерция перемотки: 0.05 — вязко, 1 — жёстко за скроллом |
| `endPad` | пустой скролл после конца видео |
| `fade` | доля паузы на появление и исчезновение контента |

Длина видео нигде не зашита — движок берёт её из самого файла. Ролик станет
длиннее — страница пересчитается сама, править нужно будет только тайминги
остановок.

## Горячие клавиши

| Клавиша | Что делает |
|---|---|
| `D` | отладочная панель: текущая секунда, позиция скролла, активная остановка |
| `T` | записать текущую секунду и сразу получить готовую строку для конфига |
| `G` | сетка для выравнивания |

## Как это устроено

Скролл делится на отрезки двух типов:

- **play** — видео едет от одной секунды к другой, длина отрезка пропорциональна
  длине куска видео;
- **hold** — видео стоит на месте, на экране контент.

Позиция скролла переводится в секунду видео по этой раскладке, дальше значение
сглаживается и выставляется в `video.currentTime` внутри `requestAnimationFrame`.
Прозрачность каждой панели считается от её собственного hold-отрезка.

## Известные ограничения

- Видео идёт без звука (`muted`) — иначе браузеры блокируют автовоспроизведение.
- На iOS видео не отдаёт кадры, пока его хоть раз не запустили: движок делает
  скрытый `play()`/`pause()` на первом касании.
- Если перемотка всё равно тормозит, есть запасной путь — разложить ролик в
  JPEG-кадры (`scripts/extract-frames.sh`) и рисовать их в `<canvas>`.
- Хостинг под прототип обязан отдавать Range-запросы. GitHub Pages, Netlify,
  Vercel — умеют. Самописный статик-сервер стоит проверить.

## Структура

```
index.html               разметка сцены
css/style.css            оформление, переменные наверху файла
js/timeline.js           КОНФИГ: путь к видео, тайминги, контент остановок
js/scroll-video.js       движок: скролл → время видео → прозрачность панелей
scripts/serve.js         локальный сервер с поддержкой Range
scripts/encode-video.sh  перекодирование видео под перемотку
scripts/extract-frames.sh запасной путь: раскладка в JPEG-кадры
assets/video/            видео
assets/images/           ассеты остановок
docs/TIMINGS.md          табличка для таймингов
```
