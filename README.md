# Копайлот — прототип со скролл-видео

Видео на фоне, привязанное к скроллу. Пользователь крутит колесо — ролик
перематывается кадр за кадром. На заданных интервалах видео почти замирает
и поверх кадра появляется ассет; крутим дальше — ассет уходит, ролик уезжает
к следующей остановке.

Чистый HTML/CSS/JS, без сборки и зависимостей.

---

## Запуск

```bash
node scripts/serve.js
# открыть http://localhost:8000
```

**Открывать надо именно через этот сервер**, не двойным кликом по файлу и не
через `python3 -m http.server`. Для перемотки видео браузеру нужны HTTP
Range-запросы; питоновский сервер их не отдаёт — ролик загрузится, но
намертво встанет на нулевой секунде, и будет казаться, что сломан скролл.

Кадр макета — 1440×900. Он масштабируется под окно целиком, поэтому ассеты
всегда ложатся на видео пиксель в пиксель. Если пропорции окна другие, по
краям появляются поля (переключается в `design.fit`).

## Горячие клавиши

| Клавиша | Что делает |
|---|---|
| `D` | панель отладки: секунда, таймкод, активная остановка |
| `T` | записать текущий таймкод в формате `СС_КК` |
| `G` | сетка по кадру макета |
| `H` | спрятать ассеты, посмотреть чистое видео |

---

## Как устроен таймлайн

Скролл делится на отрезки двух типов:

- **hold** — остановка. Видео медленно проходит интервал ассета: 3 секунды
  ролика растянуты почти на два экрана прокрутки, поэтому картинка выглядит
  замершей, но заложенная в неё анимация продолжает идти. Поверх — ассет.
- **play** — переход. Видео идёт быстро, ассетов на экране нет.

Интервалы взяты из имён файлов ассетов — в них зашит порядок и таймкод:

| Ассет | Интервал | Секунды | Что в кадре |
|---|---|---|---|
| `01. framework` | `00_00 – 03_00` | 0.00 – 3.00 | самолёт уходит от скалы |
| `02. course` | `05_00 – 06_00` | 5.00 – 6.00 | подлёт к кабине, появляется пилот |
| `03. book` | `07_20 – 09_00` | 7.67 – 9.00 | приборная панель, книга на торпеде |
| `04. reviews` | `11_20 – 14_00` | 11.67 – 14.00 | ровный кремовый фон |
| `05. conference` | `15_00 – 17_00` | 15.00 – 17.00 | ровный кремовый фон |

Отдельно стоит `00. static header` — шапка сайта. Она лежит поверх всего
и видна на всём прототипе, к таймлайну не привязана.

Формат `СС_КК` — секунды и кадры при 30 fps, как в экспорте. `07_20` = 7.667 с.
Движок разбирает и такую запись, и просто число в секундах.

## Настройка

Всё в `js/timeline.js`.

```js
stops: [
  { name: 'course',
    image: 'assets/images/02. course. 05_00 – 06_00.png',
    from: '05_00',
    to:   '06_00' }
]
```

| Поле остановки | Что делает |
|---|---|
| `from` / `to` | интервал видео, на котором ассет на экране |
| `image` | путь к ассету |
| `hold` | длина остановки в экранах, переопределяет `holdScreens` |
| `lead` | длина перехода перед остановкой в экранах |
| `freeze` | `true` — заморозить кадр на `from`, вообще без движения |

| Общая настройка | Что делает |
|---|---|
| `design.width/height` | размер кадра макета, сейчас 1440×900 |
| `design.fit` | `contain` — кадр целиком с полями, `cover` — заполнить окно |
| `scroll.screensPerSecond` | скорость переходов: экранов скролла на секунду видео |
| `scroll.holdScreens` | длина остановки по умолчанию |
| `scroll.fadeScreens` | сколько скролла уходит на появление и уход ассета |
| `scroll.smoothing` | инерция перемотки: 0.05 — вязко, 1 — жёстко за скроллом |
| `scroll.tailScreens` | длина хвоста после последней остановки |
| `video.fps` | нужен, чтобы разбирать таймкоды `СС_КК` |
| `header.image` | статичный слой поверх всего, `null` — выключить |

### Про `lead`

С 9-й секунды и до конца ролика картинка не меняется — там ровный кремовый
фон. Если считать длину перехода пропорционально секундам, между «Книгой»
и «Обзорами» получается два с лишним экрана пустого скролла. Поэтому у двух
последних остановок длина входа задана вручную: `lead: 0.5`.

Правило простое: пока в ролике что-то происходит, длину перехода считаем
по секундам; там, где ролик стоит, задаём вручную.

Длительность ролика нигде не зашита — движок берёт её из файла. Видео станет
длиннее, страница пересчитается сама, править нужно будет только интервалы.

## Обновление видео

```bash
./scripts/encode-video.sh assets/video/source/copilot-main-video.mp4
```

Скрипт кладёт результат в `assets/video/main.mp4`. Ключевой кадр ставится на
каждом кадре ролика — без этого перемотка скроллом дёргается. Текущий файл
весит 20 МБ при исходных 15 МБ, то есть плата за перемотку почти нулевая:
плоская анимация жмётся хорошо.

**После замены ролика скрипт нужно прогнать заново** — прототип играет
`main.mp4`, а не то, что лежит в `source/`.

## Структура

```
index.html               разметка сцены и кадра
css/style.css            оформление
js/timeline.js           КОНФИГ: видео, интервалы, ассеты
js/scroll-video.js       движок: скролл → время видео → прозрачность ассетов
scripts/serve.js         локальный сервер с поддержкой Range
scripts/encode-video.sh  перекодирование видео под перемотку
scripts/extract-frames.sh запасной путь: раскладка в JPEG-кадры
assets/video/main.mp4    видео для прототипа
assets/video/source/     исходник как прислали
assets/images/           ассеты остановок
```

## Известные ограничения

- Видео идёт без звука (`muted`), иначе браузеры блокируют автовоспроизведение.
  В исходнике звуковая дорожка есть, при перекодировании она выбрасывается.
- На iOS видео не отдаёт кадры, пока его хоть раз не запустили: движок делает
  скрытый `play()`/`pause()` при первом касании.
- Прототип рассчитан на десктоп. На мобилке кадр 1440×900 сожмётся в узкую
  полосу посреди экрана — под телефоны нужна отдельная раскладка ассетов.
- Хостинг обязан отдавать Range-запросы. GitHub Pages, Netlify, Vercel умеют.
- Если перемотка где-то тормозит, есть запасной путь — разложить ролик в
  JPEG-кадры (`scripts/extract-frames.sh`) и рисовать их в `<canvas>`.
